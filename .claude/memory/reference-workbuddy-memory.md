`C:\work\.workbuddy\memory\`（不在 MyTeamWork 仓库内，未被 git 跟踪）是 2026-08 以来的长期记忆，按日期归档 + 四份主题上下文：

- `MEMORY.md` — 索引：端口表、红线、环境坑、常用环境路径
- `项目上下文-报表推送与部署细节.md` — SD1~SD4 口径、日期开关、企微推送、部署（做报表前先读）
- `项目上下文-MyTeamWork全栈.md` — 全栈 + SSO 全景
- `项目上下文-经营驾驶舱3004.md` — 驾驶舱
- `数据中台项目上下文.md` — DWD/DWS
- `YYYY-MM-DD.md` — 每日工作日志（2026-08-13 起，最近 2026-11-06）

**How to apply:** 口径类问题先 grep 这些文件，多数历史踩坑只在这里有记录。本记忆库不重复抄写它们，只记仓库文档与 `CLAUDE.md` 里没有的事实，并用链接指回。
